# LLM 企业 Gateway 平台需求文档

## 1. 项目概述

本项目旨在构建一个统一的 LLM 企业 Gateway 平台，作为企业访问外部 LLM 服务（如 OpenAI, Anthropic, Google Gemini 等）的单一入口。该平台将提供统一的 API 端点，兼容 OpenAI 标准协议，并为企业员工提供子账户管理、精细化的权限管控、流量控制以及详尽的数据监控和分析功能。

---

## 2. 核心功能需求

### 2.1 统一模型接入与协议兼容

**用户故事**：作为平台管理员，我希望能够统一管理多个外部 LLM 供应商，以便为开发者提供一致的接入体验并优化成本。

**验收标准**：
1.1 **[Ubiquitous]** 系统应提供统一的 API 端点（如 `/v1/chat/completions`）以转发请求至后端供应商。
1.2 **[Ubiquitous]** 系统应支持 OpenAI V1 协议的完全兼容，确保第三方工具（如 Chatbox, Cursor）可无缝接入。
1.3 **[Event-driven]** 当管理员在后台配置新的模型供应商时，系统应能够动态更新路由表。
1.4 **[Optional]** 在 Phase 2 阶段，系统应支持原生 Gemini 和 Claude 协议的自动识别与转换。

---

### 2.2 子账户与身份管理

**用户故事**：作为平台管理员，我希望能够为企业员工创建独立的子账户，以便进行资源分配和审计。

**验收标准**：
2.1 **[Ubiquitous]** 系统应支持手动创建、编辑和禁用子账户。
2.2 **[Event-driven]** 当用户首次登录时，系统应强制要求其修改初始密码。
2.3 **[State-driven]** 当子账户处于“禁用”状态时，系统应拒绝该账户的所有 API 请求。

---

### 2.3 权限管控 (RBAC)

**用户故事**：作为平台管理员，我希望能够基于角色分配模型访问权限，以确保敏感资源仅被授权人员使用。

**验收标准**：
3.1 **[Ubiquitous]** 系统应支持定义不同的角色（如管理员、普通开发者），并为每个角色分配允许访问的模型列表。
3.2 **[Unwanted Behavior]** 如果用户尝试访问未被授权的模型，系统应返回 `403 Forbidden` 错误。
3.3 **[Ubiquitous]** 系统应支持按团队维度进行资源隔离，支持为特定团队分配独立的主密钥池。

---

### 2.4 流量与成本控制

**用户故事**：作为平台管理员，我希望能够设置速率限制和消费配额，以防止 API 滥用并控制企业总支出。

**验收标准**：
4.1 **[State-driven]** 当用户的请求速率超过设定的阈值时，系统应返回 `429 Too Many Requests`。
4.2 **[Unwanted Behavior]** 如果团队或用户的月度预算已耗尽，系统应拒绝后续请求并返回 `402 Payment Required` 或相应错误码。
4.3 **[Event-driven]** 当团队消费达到预算的 90% 时，系统应向管理员发送告警。

---

### 2.5 数据监控与分析

**用户故事**：作为平台管理员，我希望查看全局的用量统计，以便进行内部核算和模型选型决策。

**验收标准**：
5.1 **[Ubiquitous]** 系统应提供可视化仪表盘，展示总请求数、Token 消耗、预估成本和错误率。
5.2 **[Ubiquitous]** 系统应支持按用户、团队和模型维度对统计数据进行下钻分析。
5.3 **[Event-driven]** 当发生 API 错误时，系统应详细记录错误类型、状态码及耗时，以便进行排障。

---

### 2.6 API 密钥管理

**用户故事**：作为开发者，我希望能够自助生成和管理虚拟 API 密钥，以便在我的应用中安全地调用服务。

**验收标准**：
6.1 **[Event-driven]** 当开发者点击“生成新密钥”时，系统应生成一个唯一的、仅显示一次的哈希密钥。
6.2 **[Event-driven]** 当开发者吊销某个密钥时，系统应立即停止该密钥的鉴权效力。
6.3 **[State-driven]** 所有的 API 密钥在数据库中应以加密或哈希形式存储。

---

## 3. 非功能性需求

### 3.1 性能与可用性
- **[Ubiquitous]** Gateway 自身处理引入的额外延迟应低于 50ms。
- **[Ubiquitous]** 系统核心网关服务的可用性目标应为 99.95%。

### 3.2 安全性
- **[Ubiquitous]** 所有的外部供应商主密钥必须加密存储。
- **[Ubiquitous]** 所有的网络传输必须强制使用 TLS/SSL。
